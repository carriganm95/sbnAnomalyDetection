## Good run and bad run histograms

This subdirectory contains the histograms of pulse integrals of good runs (plotted in cold color) and
bad runs (plotted in warm color). The error bars are plotted as sample distribution
error (square root of the pulse integral value). The histograms are plotted in 500 channels
intervals. If a channel interval doesn't exist (e.g., 0-500), then the corresponding
channel ranges have only 0 integral values.

Note: the good and bad runs here only serve as our initial exploration, and they are not representative
of all potential good and bad runs. The pulse integral density and event numbers are also fewer than 
several other runs, probably due to detector trigger settings.
